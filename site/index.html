Four levels. Nothing is silently erased.

Every rule in the file carries one of these. The level decides what the interface will even offer you.

  1. safe

    One click, straight to the Trash.

    Regenerated automatically by the tool that made it.

  2. check first

    Confirm, with the reason shown.

    Safe to remove, but you'll pay to rebuild or re-download it.

    ~/go/pkg/mod
  3. command

    You get the command. There is no delete button.

    VACS refuses to touch a live VM disk. It copies the official command instead.

    docker system prune -a
  4. never

    Measured, never offered.

    Shown so the number adds up. No action exists for it.

    system-critical paths

Install.

Four steps, about a minute. macOS 14 Sonoma or later on Apple Silicon.

  1. 1.0

    Download the disk image.

    Built from the tagged commit and attached to the GitHub release.

    VACS.dmg

    latest release

  2. 2.0

    Drag VACS.app into Applications.

    Open the DMG and drop it in. Then eject the image.

  3. 3.0

    Clear the quarantine flag on first launch.

    Builds are ad-hoc signed, not Apple-notarized — that needs the $99/year Developer Program. Right-click the app and choose Open, or run this once:

    Terminal

    xattr -cr /Applications/VACS.app
  4. 4.0

    Grant Full Disk Access, then scan.

    System Settings → Privacy & Security → Full Disk Access → enable VACS. macOS protects ~/Library, so without it the sizes read as zero. Then press Smart Scan on Overview.

Or build it yourself.

Plain swiftc — Command Line Tools only, no Xcode project, no package manager.

Terminal

git clone https://github.com/prajwal2308/VACS.git
cd VACS
./scripts/build-app.sh --run

→ VACS self-test: OK (96 rules loaded)

Fair questions.

Can it permanently delete my files?

Not during normal cleanup — everything moves to the macOS Trash, and Put Back works until you empty it. Permanent deletion only happens if you explicitly pick Delete Permanently or Empty Trash in the Trash view.

Why does macOS say it's from an unidentified developer?

Releases are ad-hoc signed, not notarized — notarization requires Apple's $99/year Developer Program. Right-click → Open once, or run xattr -cr /Applications/VACS.app.

Why does it need Full Disk Access?

macOS shields ~/Library and app container directories from ordinary processes. Without the grant, VACS can't measure the caches that are actually costing you space. It's one toggle, and the app still makes no network calls.

Does it phone home?

No analytics, no update pings, no crash reporting, no cloud. Zero outbound requests — the source is right there if you want to check.

Does it work on Intel Macs?

Release builds target Apple Silicon. On Intel, build from source with ./scripts/build-app.sh.

What does it cost?

Nothing. MIT licensed, and it will stay that way.
