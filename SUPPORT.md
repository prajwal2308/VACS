| Need | Action |
|------|--------|
| Install or FDA issues | Read [docs/INSTALL.md](docs/INSTALL.md) |

## System requirements

- macOS 14.0 (Sonoma) or later
- Apple Silicon or Intel
- Xcode Command Line Tools for building from source (`xcode-select --install`)
